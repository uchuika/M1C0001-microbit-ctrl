# M1C0001-microbit-ctrl

micro:bit のコントローラーから、SIYEENOVE の micro:bit カー「M1C0001（Pybit）」を制御するサンプルです。

## ファイル

| ファイル | 内容 |
|---|---|
| `microbit-m1c-controller.hex` | コントローラー側 micro:bit 用プログラム（MakeCode） |
| `microbit-motor-test.hex` | モーター動作確認用プログラム（MakeCode） |

## 使い方

1. micro:bit を USB で接続し、`MICROBIT` ドライブに hex ファイルをドラッグ＆ドロップして書き込みます。
2. 中身を確認・編集する場合は [MakeCode](https://makecode.microbit.org/) を開き、「インポート」から hex ファイルを読み込みます。
